01소개

다섯 살에 처음 컴퓨터를 만났고, 그때부터 게임에 빠졌습니다. 처음 해 본 카트라이더에서 같은 트랙을 달려도 카트마다 드리프트 조작감과 속도가 다르다는 걸 느꼈고, 그 차이가 왜 생기는지 궁금했습니다.

그 궁금증으로 컴퓨터소프트웨어학과에 진학했습니다. 지금은 게임이 의도대로 동작하는지 확인하고, 문제를 찾으면 다른 사람이 그대로 따라 할 수 있게 기록하는 일을 목표로 게임 QA를 준비하고 있습니다.

요즘은 AI 도구를 활용해 반복 작업을 자동화하는 연습을 하고 있습니다. 아래 프로젝트와 트러블슈팅 기록은 모두 그 과정에서 직접 부딪히며 만든 결과입니다.

"취업준비" 공고 수집 자동화

PowerShell · Claude Code 스킬

"취업준비"라고 입력하면 두 채용 사이트의 QA 공고를 모아, 정리 노트와 위의 공고 보드를 자동으로 만드는 도구입니다.

  • 게임잡은 목록을 불러오는 요청에 직종 코드(QA·테스터)와 등록일순 정렬을 넣어 수집
  • 알바몬은 페이지에 들어 있는 공고 데이터를 읽고, 여러 검색어 결과를 합친 뒤 중복 제거
  • "6시간 전", "3일 전" 같은 등록 표시를 날짜로 바꿔 최근 7일 공고만 선택
  • 한 사이트가 실패해도 나머지 결과는 만들고 실패 사실을 알림. 공개 업로드는 실행 전에 확인

04트러블슈팅 기록

프로젝트를 만들며 실제로 만난 문제를 버그 리포트 형식으로 정리했습니다.

ISSUE-001 · Git RESOLVED

Git을 설치했는데 터미널이 git 명령을 인식하지 못함

현상
'git' 용어가 cmdlet ... 으로 인식되지 않습니다 오류
원인
Git 설치 전에 열어 둔 터미널은 새 프로그램 위치(PATH)를 모름
해결
PATH를 다시 불러오는 명령을 실행하거나 터미널을 다시 열어 해결
ISSUE-002 · GitHub RESOLVED

내 저장소에 업로드했는데 권한 거부(403)

현상
Permission to kwakjae93/qa-jobs.git denied to (다른 계정)
원인
공용 컴퓨터에 다른 사람의 GitHub 계정이 기본 로그인으로 저장되어 있었음
해결
그 계정 정보는 건드리지 않고, 이 저장소 주소에만 내 계정 이름을 넣어 내 계정으로 로그인. 작업 후 내 로그인 정보는 삭제
ISSUE-003 · GitHub Pages RESOLVED

업로드는 성공했는데 공개 링크가 404

현상
파일은 저장소에 있는데 페이지 주소에서 404
원인
GitHub Pages 설정이 꺼져 있었음. GitHub에 사이트 정보를 조회해 Pages가 없다는 걸 확인
해결
Settings → Pages에서 main 브랜치로 켜고, 배포 작업이 끝날 때까지 확인한 뒤 페이지 응답(200)과 내용까지 검증
ISSUE-004 · 업로드 스크립트 RESOLVED

업로드 과정에서 "최신 상태 받기" 단계가 실패

현상
cannot pull with rebase: You have unstaged changes
원인
새 파일을 저장소에 먼저 복사한 뒤 최신 상태를 받으려 해서, 바뀐 파일과 충돌
해결
최신 상태 받기 → 파일 복사 → 기록 → 업로드 순서로 바꿔 재발 방지
FINDING-005 · 데이터 검증 KNOWN LIMIT

알바몬 공고는 "신입 가능" 필터에 하나도 잡히지 않음

현상
신입만 골라 달라는 요청에 알바몬 공고가 전부 "조건 확인"으로 표시됨
조사
공고 9건의 상세 페이지를 하나씩 확인. 경력 정보가 모든 공고에 똑같이 "경력무관"으로 들어 있어 공고별 구분이 불가능함
결론
자동 분류를 믿지 않고 본문에 "신입도 환영"이 적힌 공고만 따로 표시. 한계를 노트와 페이지에 명시
