01왜 만들었나

공부한 내용은 그날 정리하지 않으면 금방 잊혀요. 매주 정리하고 포트폴리오에도 옮기는 일을 직접 하다 보니 자꾸 미루게 됐어요. 그래서 정해진 시간에 컴퓨터가 알아서 정리하고, 나는 결과만 확인하는 구조를 만들었습니다.

02동작 흐름

  1. 작업 스케줄러 · 자동금요일 19:45에 스크립트 실행로그인한 상태에서 화면에 창을 띄워 실행해요.
  2. PowerShell · 자동오늘 수정된 노트 목록 만들기설정·보관(Archive)·도구 폴더는 빼고, 오늘 날짜로 바뀐 .md 파일만 골라요.
  3. Claude · 자동학습 요약 노트 작성날짜_학습요약.md에 "한 문장 요약, 오늘 배운 것, 기억할 점, 다음에 해 볼 것"을 정리해요.
  4. Claude · 자동포트폴리오 "주간 학습 기록" 갱신HTML에 표시해 둔 칸 안에만 오늘 항목을 추가하고, 최신 8개만 남겨요.
  5. PowerShell · 자동망가진 곳이 없는지 확인표시 칸과 HTML 끝부분이 그대로인지 확인하고, 문제가 있으면 업로드를 멈춰요.
  6. 사람 · 로그인 한 번GitHub 업로드로그인 창이 뜨면 로그인해요. 업로드가 끝나면 로그인 정보를 지워요.
  7. GitHub Actions · 자동검사 → 사이트 배포 → 텔레그램 알림성공해도 실패해도 결과를 텔레그램으로 받아요.

03구성 파일

파일역할
run-weekly.ps1전체 흐름을 실행하는 스크립트. 실행 기록을 날짜별 로그로 남겨요

.github/workflows/deploy.ymlGitHub에서 기본 검사, Pages 배포, 텔레그램 알림을 해요

04설계하며 정한 것

AI에게 어디까지 맡길까?파일 읽기·쓰기만 허용

예약 실행되는 Claude는 명령 실행과 인터넷 사용을 막았어요. 사람이 보지 않는 동안 할 수 있는 일을 최소로 줄였어요.

공개 페이지를 AI가 고쳐도 될까?표시한 칸 안만 수정

HTML에 시작·끝 표시를 넣고 그 사이만 고치게 했어요. 다른 사람 이름, 계정, 개인 일상은 넣지 않도록 지시문에 적었어요.

공용 컴퓨터에서 로그인은?저장하지 않기

완전 자동 대신 업로드 때 한 번 로그인하는 방식을 골랐어요. 금요일 19:45는 수업 중이라 컴퓨터 앞에 있는 시간이에요.

기록할 게 없는 날은?지어내지 않기

오늘 바뀐 노트가 없으면 "기록된 학습 내용이 없어요"라고만 쓰고 포트폴리오는 고치지 않아요.

Git 폴더는 어디에?클라우드 동기화 폴더 밖

노트는 클라우드 드라이브에 있지만, 업로드용 Git 복사본은 로컬에 따로 두어 동기화 충돌을 막았어요.

확장 프로그램이 업데이트되면?실행 파일을 매번 찾기

Claude 실행 파일 경로에 버전 번호가 들어 있어서, 실행할 때마다 가장 최신 파일을 찾아 써요.

05핵심 코드

$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Friday -At "19:45"
$principal = New-ScheduledTaskPrincipal -UserId $user -LogonType Interactive

작업 스케줄러 등록. 로그인 창이 보여야 해서 "로그인한 상태에서 화면에 띄워 실행"으로 설정했어요.

$prompt | & $claude -p `
  --allowedTools "Read,Write,Edit,Glob,Grep" `
  --disallowedTools "Bash,PowerShell,WebFetch,WebSearch"

Claude 예약 실행. 허용 도구를 파일 읽기·쓰기로 제한했어요.

- name: 텔레그램 알림
  if: always()   # 실패해도 알림을 보내기 위해 꼭 필요

GitHub Actions. 이 줄이 없으면 앞 단계가 실패했을 때 알림 단계가 건너뛰어져요.

06트러블슈팅

ISSUE-W01 · PowerShellRESOLVED

업로드 스크립트를 시험했더니 아무 반응 없이 멈춤

현상
"저장소를 내려받아요" 메시지 다음에서 멈추고, git 프로세스도 생기지 않음
원인
스크립트 안에 만든 Git 함수가 git 명령과 이름이 겹침. PowerShell은 대소문자를 구분하지 않아서 함수가 자기 자신을 끝없이 호출
해결
함수 이름을 Invoke-Git으로 바꾸고 git.exe를 직접 호출. 가짜 저장소로 처음부터 다시 시험
ISSUE-W02 · 인코딩PREVENTED

한글 지시문이 AI에게 ?로 깨져 전달될 위험

원인
Windows PowerShell 5.1은 다른 프로그램에 글자를 넘길 때 기본으로 ASCII를 써서 한글이 깨짐
예방
지시문을 넘기기 직전에 $OutputEncoding을 UTF-8로 설정. 볼트 복사본 시험에서 요약이 한글로 정상 작성되는 것을 확인
ISSUE-W03 · 오류 처리PREVENTED

경고 메시지 하나로 스크립트 전체가 멈출 위험

원인
오류가 나면 바로 멈추게 설정한 상태에서 외부 프로그램의 경고 출력까지 오류로 취급됨
예방
AI 실행 구간만 "계속 진행"으로 바꾸고, 대신 종료 코드와 결과 줄(RESULT)로 성공 여부를 판단
ISSUE-W04 · 파일 시스템RESOLVED

폴더 이름을 영문으로 바꾸려는데 "사용 중" 오류

현상
The process cannot access the file because it is being used by another process
원인
열어 둔 터미널 하나의 현재 위치가 그 폴더 안이었음
해결
터미널을 상위 폴더로 옮긴 뒤 다시 이름 변경

07테스트

실제 노트와 사이트를 망가뜨리지 않도록, 진짜 환경과 분리해서 먼저 시험했어요.

시험방법결과
업로드 처음 실행로컬에 만든 가짜 저장소로 업로드PASS 파일 2개 업로드
바뀐 게 없을 때같은 상태로 한 번 더 실행PASS 아무것도 올리지 않음
요약 + 포트폴리오 갱신노트 복사본에서 업로드 없이 실행PASS 노트 5개 요약, 약 40초
수정 범위원본과 결과 HTML 비교PASS 표시 칸 안의 항목 1개만 추가
HTML 구조여는 태그와 닫는 태그 개수 비교PASS 짝이 모두 맞음

08배운 점

  • 자동화는 "사람이 안 볼 때"를 기준으로 설계해야 한다. 실패하면 멈추고, 기록을 남기고, 알려 주는 장치가 기능만큼 중요했어요.
  • 테스트는 진짜 환경과 떨어진 곳에서 먼저. 가짜 저장소와 노트 복사본 덕분에 멈춤 버그를 실제 데이터에 영향 없이 찾았어요.
  • AI에게 맡길수록 범위를 좁게. 쓸 수 있는 도구와 고칠 수 있는 칸을 정해 두니 결과를 믿고 볼 수 있었어요.
